TL Studio یک Command Runner در Scope همان Project دارد که روی Local Process Manager خود برنامه ساخته شده است.

## Command در Scope Project

هر Command با Project فعال به‌عنوان Working Directory اجرا می‌شود. Output داخل Workspace Stream می‌شود و History آن به‌صورت Bounded در Local State نگه داشته می‌شود.

بعد از Project Switch، Commandهای جدید CWD مربوط به Project جدید را می‌گیرند.

## Stop کردن Process

Process طولانی را می‌توانید از داخل TL Studio Stop کنید. در Windows، Stop کل Process Tree را می‌بندد تا Child Processهایی مثل Dev Server ناخواسته باقی نمانند.

Stop عمدی به‌عنوان حالت متوقف‌شده ثبت می‌شود، نه Crash نامشخص.

## استفاده توسط Native Agent

در Stable v0.3، Native Tool Executor از همین Process Layer برای Tool زیر استفاده می‌کند:

```text
terminal.command
```

Command Tool قبل از اجرا نیاز به Permission دارد. چون Execution حساس است، Approval مربوط به Native Terminal به Rule دائمی قابل Remember تبدیل نمی‌شود.

## محدودیت فعلی

Terminal فعلی **Full PTY Terminal Emulator نیست**. برای Project Command، Build/Test، Script و Processهایی طراحی شده که با Command Runner کار می‌کنند.

Interactive TUIهایی که Terminal Device واقعی می‌خواهند ممکن است درست کار نکنند.

## Security

Command با Permissionهای User سیستم اجرا می‌شود. Local بودن به معنی Safe بودن هر Command نیست. قبل از اجرا یا Approval، Commandهای مخرب، Network، Package Manager یا Credential-sensitive را بررسی کنید.
