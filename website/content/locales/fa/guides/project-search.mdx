Project Search توسط خود TL Studio اجرا می‌شود و فقط Project Local فعال را Scan می‌کند.

## بازکردن Search

از بخش Search یا Shortcut استاندارد استفاده کنید:

```text
Windows / Linux: Ctrl + Shift + F
macOS:           Cmd + Shift + F
```

## Search Controlها

نسخه فعلی از این موارد پشتیبانی می‌کند:

- Case-sensitive Search؛
- Include Patternهای سبک؛
- Exclude Patternهای سبک؛
- Group شدن Resultها براساس File؛
- بازشدن مستقیم Match داخل Editor.

با کلیک روی Result، File مربوط باز یا Active می‌شود و محدوده Match انتخاب می‌شود.

## Local و Bounded

Search هیچ Shell Commandی نمی‌سازد و به Search Binary خارجی نیاز ندارد. Scan از Filesystem Boundary خود TL Studio انجام می‌شود.

برای Security و Performance، Symlinkها Follow نمی‌شوند، Fileهای Binary/Non-UTF8 نادیده گرفته می‌شوند، اندازه File و تعداد Resultها Limit دارند و Directoryهای سنگین یا Generated زیر به‌صورت پیش‌فرض Skip می‌شوند:

```text
.git
node_modules
dist
build
out
coverage
.next
```

برای Projectهای بزرگ می‌توانید با Include/Exclude دامنه Search را محدودتر کنید.
