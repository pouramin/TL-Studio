## Project Local

Project فعال مرز کاری TL Studio است. Files، Editor Tabs، Search، Terminal Commandها، Preview، Sessionها، Changes، Agent Context، Permission Requestها و Questionها همگی Project فعال را دنبال می‌کنند.

با Project Switch، Attachmentهای Pending در Composer پاک می‌شوند. اگر Editor تغییرات Save‌نشده داشته باشد، TL Studio قبل از دورریختن آن‌ها تأیید می‌گیرد.

## Sessionها

TL Studio Sessionهای Coding را در Workspace نمایش و مدیریت می‌کند و Agent Execution پشت Runtime Contract Local باقی می‌ماند. می‌توانید Session بسازید، Rename یا Delete کنید و Session قبلی را دوباره باز کنید.

ساخت Session جدید Attachmentهای ارسال‌نشده را پاک می‌کند. Attachmentهایی که قبلاً Send شده‌اند روی Message مربوط به خودشان باقی می‌مانند.

برای Sessionهای خیلی قدیمی Alpha یک Compatibility Bridge فقط‌خواندنی وجود دارد. آن Historyها به Project ثبت‌شده‌ی خودشان Scope شده‌اند و از مسیر Legacy تغییر داده نمی‌شوند.

## Message و Live Activity

TL Studio برای Task فعال فقط منتظر اولین HTTP Response نمی‌ماند؛ Session State و Live Eventها را دنبال می‌کند و Text، Reasoning، Tool، File Activity، Permission، Question و Attachmentها را در طول Run نمایش می‌دهد.

## Usage Summary

هرجا Execution Data موجود باشد، TL Studio مصرف هر Turn و مجموع Project مثل Token، Request، Time، Reasoning و Cache را نشان می‌دهد. این اطلاعات Summary محلی Workspace هستند و به سرویس ابری TL Studio ارسال نمی‌شوند.
