TL Studio به‌عنوان یک Local Application طراحی شده، نه Coding Service که از راه دور Expose شود.

## Loopback-only Control Surface

Browser Server فقط Loopback Address را قبول می‌کند. Agent Engine همراه برنامه هم روی Loopback اجرا می‌شود و به‌عنوان Endpoint عمومی جدا در اختیار Browser قرار نمی‌گیرد.

هر اجرا یک Backend Credential تصادفی تازه می‌سازد که سمت Server باقی می‌ماند و TL Studio Authentication لازم را از داخل Adapter تزریق می‌کند.

## Browser Origin Check

Requestهای Browser با Local Control Origin بررسی می‌شوند و UI با Content Security Policy محدودکننده Serve می‌شود.

## Project Filesystem Boundary

عملیات File از Browser به Project انتخاب‌شده محدود است.

TL Studio، Path Traversal، Symlink-parent Escape، Project-root Mutation و تغییر Protected Git Metadata را رد می‌کند. Symlink مستقیم مثل File عادی قابل‌Edit در نظر گرفته نمی‌شود.

Save معمولی Revision Token دارد تا External Change بی‌صدا Overwrite نشود.

## Preview Isolation

Project Web Code روی Origin دارای دسترسی Control API اجرا نمی‌شود. Live Preview از Loopback Origin جدا استفاده می‌کند و فقط Preview URL محلی پذیرفته می‌شود.

## Local Editor Assets

Editor Code و Syntax-color Assetها همراه خود برنامه هستند. Runtime Code یا Worker مربوط به Editor از CDN Load نمی‌شود.

## Terminal Trust

Terminal Commandها با Permissionهای User سیستم اجرا می‌شوند. Loopback بودن Command خطرناک را امن نمی‌کند؛ قبل از اجرای Commandهای مخرب یا Credential-sensitive آن‌ها را بررسی کنید.

## Provider Credential

Custom Provider Definition متعلق به TL Studio است، اما در v0.2 نگه‌داری API Key هنوز به Local Credential Store مربوط به Agent Engine سپرده شده است. Key داخل `providers.json` خود TL Studio یا Browser Storage قرار نمی‌گیرد.

## Agent Permission

Agent در صورت گرفتن Permission لازم می‌تواند Project Fileها را Read/Write کند و Command اجرا کند. Permission Request حساس را قبل از Approval بررسی کنید.


## تغییرات Security در Development Preview

در v0.3 خصوصی، Permission Policy Store متعلق به TL Studio اضافه شده است. Ruleهای Remembered در Scope همان Project داخل `permissions.json` به‌صورت Local ذخیره می‌شوند و فقط Allow Decisionهایی را پوشش می‌دهند که Matcher Token دقیق و قابل‌استفاده از Runtime داشته باشند.

Requestهای حساس `skillShell` و `sandboxEscalation` هیچ‌وقت Persist یا Auto-approve نمی‌شوند و Requestهایی که Persistent Approval را Disable می‌کنند Interactive باقی می‌مانند. Ruleهای Remembered از Settings قابل مشاهده و حذف هستند.

در همین خط Development، Monaco و Workerهایش هم کاملاً Local Bundle می‌شوند و Editor Asset از CDN دریافت نمی‌شود.
