**v0.2.0 نسخه Stable فعلی TL Studio است.**

## Stable و Development Line

- `main` خط Stable Production است؛
- `dev` خط Development نسخه بعدی است؛
- npm Stable از dist-tag برابر `latest` استفاده می‌کند؛
- Build آزمایشی از Tag جدا مثل `alpha` استفاده می‌کند.

اجرای Stable:

```bash
npx --yes tl-studio
```

اجرای Prerelease وقتی موجود باشد:

```bash
npx --yes tl-studio@alpha
```

پکیج npm فقط Launcher سبک Pin‌شده به GitHub Release متناظر است. OS/Architecture را تشخیص می‌دهد، Archive رسمی را می‌گیرد، SHA-256 را Verify می‌کند، Local Cache می‌سازد و TL Studio را اجرا می‌کند.

## Portable Release

Archiveهای Portable شامل این‌ها هستند:

- فایل اجرایی TL Studio؛
- Agent Engine سازگار همراه برنامه؛
- Licenseهای TL Studio؛
- Third-party Notice/Licenseهای لازم.

User لازم نیست Agent Engine را جدا نصب یا مدیریت کند.

Stable Promotion فقط بعد از Checkهای خودکار و Validation دستی Release Candidate انجام می‌شود و Development آزمایشی بدون تغییر مسیر `latest` ادامه پیدا می‌کند.
