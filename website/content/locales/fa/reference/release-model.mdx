**v0.2.1 نسخه Stable فعلی TL Studio است.**

## Stable و Development Line

- `main` خط Stable Production است؛
- `dev` خط Development نسخه بعدی است؛
کاربر Stable نسخه Portable منتشرشده در GitHub Releases را اجرا می‌کند و Development آزمایشی روی خط جدا باقی می‌ماند.

## Portable Release

Archiveهای Portable شامل این‌ها هستند:

- فایل اجرایی TL Studio؛
- Agent Engine سازگار همراه برنامه؛
- Licenseهای TL Studio؛
- Third-party Notice/Licenseهای لازم.

User لازم نیست Agent Engine را جدا نصب یا مدیریت کند.

Stable Promotion فقط بعد از Checkهای خودکار و Validation دستی Release Candidate انجام می‌شود و Development آزمایشی بدون تغییر خط Stable ادامه پیدا می‌کند.
