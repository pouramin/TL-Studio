نسخه Stable فعلی:

```text
v0.3.0
```

## خط Stable

Branch `main` فقط برای Production Stable است.

اجرای Stable:

```bash
npx --yes tl-studio
```

پکیج npm یک Launcher سبک Pin‌شده به GitHub Release پایدار متناظر است. Platform/Architecture را تشخیص می‌دهد، Archive رسمی را دانلود می‌کند، SHA-256 را Verify می‌کند، Local Cache می‌سازد و TL Studio را اجرا می‌کند.

Publish روی npm فقط از `main` پایدار انجام می‌شود و مسیر `latest` را دنبال می‌کند.

## Portable Release

Build پایدار برای این Platformها منتشر می‌شود:

- Windows x64؛
- Linux x64؛
- Linux ARM64؛
- macOS Intel x64؛
- macOS Apple Silicon ARM64.

Archive شامل فایل اجرایی TL Studio، Compatibility Engine تست‌شده، Assetهای Local Monaco، Licenseهای TL Studio و Third-party Notice/Licenseهای لازم است.

## خط Development فعلی

Branch خصوصی نسخه بعدی:

```text
dev → v0.4.0-alpha.1
```

فاز 3 هنوز شروع نشده است. بعد از Promotion موفق فاز 2، Branch از Baseline پایدار v0.3.0 برای نسخه بعدی دوباره باز شده است.

Alphaهای Development روی npm Publish نمی‌شوند و GitHub Prerelease عمومی ندارند.

وقتی Development فاز بعدی شروع شود، Workflow مربوط به **Preview Build** همچنان مسیر Artifact خصوصی است. Workflow فعلی ZIP مربوط به Windows x64 می‌سازد و Artifact را 14 روز نگه می‌دارد.

## Stable Promotion

Release پایدار فقط بعد از Automated Gate و Validation دستی Promotion می‌شود.

برای v0.3، Browser Build، Go Test/Vet، Runtime Boundary، Cross-compile Platformهای پشتیبانی‌شده، Compatibility Contract، Prompt/Write واقعی، Custom Provider Contract، npm Package و Validation واقعی Windows بررسی شدند.
