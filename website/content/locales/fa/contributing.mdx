Application و Public Documentation در TL Studio Build Path جدا دارند.

## Product Development

Go Launcher و Local APIهای متعلق به TL Studio زیر `cmd/launcher/` هستند.

Source اصلی Browser Application به TypeScript در این مسیر قرار دارد:

```text
cmd/launcher/ui/
```

JavaScript کامپایل‌شده در این مسیر تولید می‌شود:

```text
cmd/launcher/web/
```

برای تغییر Product Behavior، Generated Fileهای `web/*.js` را Source اصلی در نظر نگیرید.

قبل از Browser Change:

```bash
npm install
npm run check:web
npm run build:web
go test ./...
```

## Architecture Ruleها

- Project Filesystem/Search/Process/Preview باید پشت APIهای `/local/*` خود TL Studio بمانند.
- Agent Execution Conceptها باید پشت Runtime Contract متعلق به TL Studio با `/runtime/*` بمانند.
- Browser Feature Module نباید Implementation-specific Route بسازد.
- Provider/Model Definition متعلق به Registry خود TL Studio است، نه Vendor Config داخل Browser.
- Editor/Runtime Asset جدید باید Local Bundle شود، نه CDN.
- Preview Project Code باید روی Origin جدا از Control API خود TL Studio اجرا شود.

## Internal Engineering Docs

Engineering Noteها زیر `docs/` در Repository اصلی هستند.

## Public Documentation

سایت Fumadocs زیر `website/` قرار دارد.

```bash
cd website
npm install
npm run typecheck
npm run build
```

متن User-facing باید روی **TL Studio** متمرکز بماند. اسم Agent Engine همراه برنامه فقط در Maintainer Compatibility Reference یا جایی که Attribution قانونی واقعاً لازم است بیاید.


## خط Development فعلی

خط خصوصی Development فعلی **v0.3.0-alpha.7** است.

هنگام کار روی `dev` سه Boundary مهم‌اند:

- Monaco فقط یک Editor Engine کاملاً Local و Lazy-loaded است. File Ownership، Save/Conflict Logic و Project Path Authority نباید به Monaco منتقل شوند.
- Tool Identity/Presentation Semantics متعلق به TL Studio و در `cmd/launcher/tool_registry.go` است و از `GET /local/tools` ارائه می‌شود. Registry نباید Tool اجرا کند یا Runtime Enforcement را Override کند.
- Remembered Permission Policy متعلق به TL Studio و در `cmd/launcher/permission_engine.go` است. Request حساس باید Interactive بماند و Browser باید از `/local/permissions*` استفاده کند، نه Raw Permission Route مربوط به Engine.

Preview Buildهای `dev` فقط Artifactهای GitHub Actions هستند. Alpha روی npm یا GitHub Prerelease عمومی منتشر نشود مگر اینکه Release Model عمداً تغییر کند.
