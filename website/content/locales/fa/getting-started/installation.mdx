## اجرا با یک دستور

اگر Node.js و npm نصب هستند، داخل فولدر Project این دستور را اجرا کنید:

```bash
npx --yes tl-studio
```

پکیج npm یک Launcher سبک است که به نسخه Stable فعلی TL Studio روی GitHub Release متصل می‌شود؛ Platform را تشخیص می‌دهد، Archive رسمی را دانلود می‌کند، SHA-256 را Verify می‌کند، Local Cache می‌سازد و TL Studio را اجرا می‌کند.

برای جلوگیری از بازشدن خودکار Browser:

```bash
npx --yes tl-studio --no-browser
```

## نسخه Portable

برای استفاده از نسخه Portable نیازی به Node.js نیست. فایل مناسب سیستم‌عامل را از GitHub Releases بگیرید، Extract کنید و اجرا کنید:

```text
Windows:  tl-studio.exe
Linux:    ./tl-studio
macOS:    ./tl-studio
```

Releaseهای TL Studio، Agent Runtime سازگار را داخل خودشان دارند؛ بنابراین نصب جداگانه Runtime لازم نیست.

## نسخه‌های پشتیبانی‌شده

- Windows x64
- Linux x64
- Linux ARM64
- macOS Intel x64
- macOS Apple Silicon ARM64
