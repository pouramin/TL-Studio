**v0.3.0 is the current stable TL Studio release.**

## Stable line

`main` is production-only. Stable users can launch with:

```bash
npx --yes tl-studio
```

The npm package is a lightweight launcher pinned to the matching stable GitHub Release. It detects platform/architecture, downloads the official archive, verifies SHA-256, caches it locally, and starts TL Studio.

Stable npm publishing happens from stable `main` only and tracks the `latest` path.

## Portable releases

Stable portable builds are published for:

- Windows x64;
- Linux x64;
- Linux ARM64;
- macOS Intel x64;
- macOS Apple Silicon ARM64.

Archives contain the TL Studio executable, the tested bundled compatibility engine, local Monaco assets, TL Studio license files, and required third-party notices/licenses.

## Current development line

The private next-version branch is:

```text
dev → v0.4.0-alpha.1
```

Phase 3 implementation has not started yet. The version/branch was reopened from the stable v0.3.0 baseline after successful Phase 2 promotion.

Development alphas are not published to npm and are not public GitHub prereleases.

When dev implementation resumes, the GitHub Actions **Preview Build** workflow remains the private artifact path. The current workflow produces a Windows x64 Preview ZIP and keeps artifacts for 14 days.

## Stable promotion discipline

Stable releases are promoted only after automated gates and hands-on validation.

The v0.3 promotion included proof for the Browser build, Go tests/vet, runtime-boundary rules, supported platform cross-compiles, compatibility contracts, prompt/write-file execution, custom Provider contracts, npm package behavior, and real Windows validation.
