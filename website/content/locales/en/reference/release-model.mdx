**v0.2.1 is the current stable TL Studio release.**

## Stable and development lines

- `main` is the stable production line.
- `dev` is the active next-version development line.
Stable users can use the npm launcher:

```bash
npx --yes tl-studio
```

The npm launcher tracks only the stable release line.

The current development version is **v0.3.0-alpha.7** on `dev`. Alpha builds are intentionally **not** published to npm and **not** published as public GitHub prereleases. They are produced only as GitHub Actions **Preview Build** artifacts for project testing. The current preview workflow builds Windows x64 artifacts and retains them for 14 days.

## Portable releases

Portable archives include:

- the TL Studio executable;
- the compatible bundled Agent engine;
- TL Studio license files;
- required third-party notices/licenses.

Users do not need to install or manage the Agent engine separately.

Stable promotion happens only after automated checks and hands-on validation of the release candidate. Experimental development can continue without changing the stable release line.
