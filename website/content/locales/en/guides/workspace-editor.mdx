Stable v0.3 uses **Monaco Editor 0.56.0** as the enhanced Editor engine while TL Studio remains the authority for Project files, buffers, saves, conflicts, and external-change reconciliation.

## File Explorer

From **Files** you can:

- open files;
- create files and folders;
- rename entries;
- delete entries;
- refresh the Project tree;
- reveal the active file with **Show in Folder**.

Filesystem operations are resolved inside the selected Project boundary.

## Monaco is local

Monaco and its workers are bundled with TL Studio and loaded from the local application origin. The enhanced Editor is lazy-loaded when first needed; no Editor CDN is required.

If the Monaco bundle cannot load, the lightweight textarea-based Editor remains a functional fallback.

## Multi-tab editing

Each open file has its own in-memory buffer. Clean and dirty tabs are tracked independently, so you can move between files without losing unsaved edits.

Use `Ctrl+S` on Windows/Linux or `Cmd+S` on macOS to save the active file.

Monaco also provides standard workflows such as Find/Replace and multi-cursor editing.

## Conflict protection

When TL Studio reads a file, it records a SHA-256 revision token. A normal save sends that revision back. If the file changed on disk after you opened it, TL Studio refuses to silently overwrite the newer version.

Force-save is a separate deliberate action after reviewing the conflict.

## Agent, Git, and external changes

A file can change because of the Agent, Git, a build tool, or another application.

- clean buffers follow external disk changes automatically;
- dirty buffers are preserved and marked when the disk version changes or disappears.

## Read-only preview tabs

Previewable binary/media files can open as real read-only Workspace tabs. Their content is rendered by the Preview system rather than treated as editable text.

See [Live Preview](./live-preview) for the supported capability types.

## Ask Agent from selected code

Selected Editor content can be handed to the Agent as context without manually copying the surrounding file.
