TL Studio includes a project-scoped command runner backed by its own local process manager.

## Project-scoped commands

Commands run with the currently selected project as their working directory. When you switch projects, new commands follow the new Project CWD.

Output is streamed into the workspace and kept in a bounded local history.

## Stop a process

Long-running commands can be stopped from TL Studio. On Windows, Stop terminates the process tree so child processes such as development servers are not intentionally left behind.

An intentional stop is treated as a stopped command rather than a mysterious crash.

## What the current Terminal is not

The current Terminal is **not a full PTY terminal emulator**. It is designed for project commands, build/test tasks, scripts, and processes that work in this command-runner model.

Interactive TUI applications that require a real terminal device are outside the current v0.2 foundation.

## Security

Commands execute on your machine with your user account's permissions. The Terminal being Local does not make an arbitrary command safe. Review commands before running them and be especially careful with destructive filesystem or credential operations.
