## One-command launch

If Node.js/npm is installed, run this inside the project directory you want to work on:

```bash
npx --yes tl-studio
```

The npm package is a lightweight launcher pinned to the current stable TL Studio GitHub Release. It detects the platform, downloads the official archive, verifies its SHA-256 checksum, caches it locally, and starts TL Studio.

To start without opening the browser automatically:

```bash
npx --yes tl-studio --no-browser
```

## Portable release

Download the archive for your platform from GitHub Releases, extract it, and run:

```text
Windows:  tl-studio.exe
Linux:    ./tl-studio
macOS:    ./tl-studio
```

Release archives already include the compatible agent runtime, so no separate runtime installation is required.

## Supported builds

- Windows x64
- Linux x64
- Linux ARM64
- macOS Intel x64
- macOS Apple Silicon ARM64

## Verify a download

Each release includes `SHA256SUMS.txt`. You can compare the archive checksum with the published value before running it.


## Development preview

Experimental v0.3 builds are not published to npm or GitHub Releases. They are private-to-project **Preview Build** artifacts produced from the `dev` branch in GitHub Actions. The current preview artifact is Windows x64 and is intended for testing, not as the stable installation path.

See [Development preview](../reference/development-preview).
