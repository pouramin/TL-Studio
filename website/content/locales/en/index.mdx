TL Studio is a **local development workspace with its own browser IDE and AI built in**. It brings project files, a multi-tab editor, Project Search, command execution, Live Preview, sessions, providers, permissions, attachments, changes, and Agent workflows into one fast local product.

## Product identity

The product you install and operate is **TL Studio**. The workspace, editor, project tools, provider/model definitions, recovery behavior, security boundary, packaging, and browser experience all belong to TL Studio.

```text
You
  ↓
TL Studio
  ├─ Browser IDE + Agent workspace
  ├─ Files / Editor / Search
  ├─ Terminal / Live Preview
  ├─ Sessions / Attachments / Changes
  ├─ Provider + Model registry
  └─ Local security + packaging
       ↓
Runtime contract + adapter
       ↓
Bundled agent engine
       ↓
Models / providers / agent tools
```

The bundled engine is an execution dependency behind a TL Studio-owned contract, not the public identity of the product.

## What you can do

- open a local project with the operating-system Folder Picker;
- browse, edit, create, rename, delete, and save project files;
- work across multiple editor tabs with unsaved-state and conflict protection;
- search the project and jump directly to a matching line;
- run project-scoped commands and stop long-running processes;
- preview static sites and supported Node development servers locally;
- create and manage Agent sessions;
- choose an Agent and Model;
- attach images, PDFs, and text/code files to prompts;
- manage compatible custom Provider and Model definitions from Settings;
- follow live Reasoning, Tool, and file activity;
- approve or reject Permission requests and answer interactive Questions;
- inspect per-session Changes and local usage summaries;
- recover from retryable provider failures without discarding completed file work;
- customize UI, Code, and Terminal fonts plus editor syntax theme.

## Current stable release

**v0.2.1 is the current stable TL Studio release.**

```bash
npx --yes tl-studio
```

Stable production lives on `main`. Experimental development continues separately on `dev` and prerelease npm channels.
